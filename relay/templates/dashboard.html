Démarrer le tunnel

Le tunnel se contrôle depuis votre terminal. Le bouton « Démarrer » ci-dessous copie simplement la commande à lancer.

# Installez le client (une fois)
pip install bentunnel-client

# Démarrez le tunnel vers votre port local
python -m client.main start --port 3000
# Pour stopper : Ctrl+C dans le terminal du client

Token WS prêt :

Documentation

  • Le client maintient une WebSocket ouverte vers /ws.
  • Le serveur envoie un PING toutes les 30 s — le client doit répondre PONG sous 10 s.
  • Le token JWT expire en 5 min. Le client le renouvelle automatiquement.
  • Limite : 5 Mo par requête/réponse. Timeout : 30 s.
