Exposez votre localhost au monde

BenTunnel vous donne une URL publique en HTTPS qui pointe vers votre serveur local. Pas de firewall, pas de routeur, pas de DynDNS. Un client Python, une URL.

Créer un compte Se connecter

Comment ça marche

1

Créez votre compte

Inscrivez-vous en 10 secondes. Une URL /tunnels/<votre-slug> vous est réservée.

2

Lancez le client

Le client Python ouvre une WebSocket vers le serveur Render et maintient la connexion ouverte.

3

Partagez votre URL

Tout le trafic arriving sur votre URL publique est reversé vers 127.0.0.1:<port>.

Démarrage rapide

# 1. Installez le client
pip install bentunnel-client

# 2. Connectez-vous (une fois)
python -m client.main login --email vous@example.com

# 3. Exposez votre port local
python -m client.main start --port 3000

# → Votre app est désormais disponible sur
#   {{ public_base_url }}/tunnels/<votre-slug>

Caractéristiques

  • 🔒 HTTPS automatique sur toutes les URLs publiques
  • ⚡ Authentification par JWT court (5 min) renouvelable
  • 🛡️ Mots de passe Argon2id, sessions révocables, CSRF double-submit
  • 🌐 Multi-méthode : GET, POST, PUT, PATCH, DELETE, OPTIONS
  • 📦 Corps binaires jusqu'à 5 Mo (tunneling d'uploads, images, etc.)
  • ❤️ Keep-alive automatique (PING/PONG) — Render Free reste réveillé
